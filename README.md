🌟 Stylish Portfolio Website

This project is a modern and fully responsive portfolio website built using HTML5 and CSS3.
The site has a minimalistic yet attractive design and can be used as a personal portfolio, presentation or web agency website.

🖼️ About the Project

“Stylish Portfolio” was designed from scratch, inspired by the classic Start Bootstrap theme.

The project has several sections:

Landing page (with title and call to action)

About section

Services section

Portfolio (Projects) gallery

Map integration (Google Maps)

Footer section with social media icons

🚀 Features

✅ Responsive (mobile-friendly) design
✅ Hover effects and soft transitions
✅ Google Maps integration
✅ Font Awesome icons
✅ Simple and readable code structure

🛠️ Technologies Used

HTML5

CSS3

Font Awesome
